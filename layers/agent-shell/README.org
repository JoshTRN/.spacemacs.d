#+TITLE: agent-shell layer

* Description
ACP coding agents (Claude Code, Codex, Gemini, ...) inside Emacs via
the =agent-shell= package.  The layer owns the package and puts the
common entry points on the applications prefix.

Also ships =agent-shell-dashboard= (GitHub-only, installed via a layer
recipe): a read-only landing page listing every agent session with a
triage queue and quick actions.  Its buffer starts in emacs state so
the package's single-key bindings (~c~, ~g~, ~f~, ~K~, ~?~ ...) work
untouched by evil.

Also ships =agent-shell-hq= (GitHub-only, installed via a layer
recipe): a heads-up display for juggling many sessions — a dedicated
perspective with a sidebar grouping sessions by project (=SPC a a h=),
plus a posframe peek overlay (=SPC a a P=) and LLM-generated session
labels.

Buffer-level styling (fenced tool output with language detection,
variable-pitch prose) lives in =config.el= under the AGENT-SHELL
heading, not here — it advises package internals and is easier to
iterate on there.

* Install
Add =agent-shell= to =dotspacemacs-configuration-layers= (via
=layers.el=).  The package moves here from =additional-packages.el=.

* Key bindings

| Key Binding   | Description                                        |
|---------------+----------------------------------------------------|
| ~SPC a a a~   | Switch to (or start) an agent shell                |
| ~SPC a a t~   | Toggle the agent shell window                      |
| ~SPC a a n~   | New shell (prompts for agent)                      |
| ~SPC a a T~   | New shell in a temp directory                      |
| ~SPC a a w~   | New shell in a git worktree                        |
| ~SPC a a b~   | Cycle to another agent-shell buffer                |
| ~SPC a a R~   | Resume a previous session                          |
| ~SPC a a F~   | Fork the current session                           |
| ~SPC a a k~   | Interrupt the busy agent                           |
| ~SPC a a i~   | Send clipboard image to the shell                  |
| ~SPC a a I~   | Send clipboard image, prompting for which shell    |
| ~SPC a a s~   | Take a screenshot and send it                      |
| ~SPC a a r~   | Send the active region                             |
| ~SPC a a f~   | Send the current file                              |
| ~SPC a a d~   | Open the sessions dashboard                        |
| ~SPC a a h~   | Toggle the HQ workspace (sidebar + perspective)    |
| ~SPC a a P~   | Peek at all sessions in a posframe overlay         |

Agent-specific starters are bound in the host-local config.
